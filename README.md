# VirtuShop Software Testing Portfolio

A GitHub-ready QA/SQA portfolio demonstrating manual testing, test case design, bug reporting, SQL validation, and Selenium automation.

## Skills Demonstrated
- Manual Testing
- Test Scenario & Test Case Design
- Smoke, Sanity & Regression Testing
- Bug Reporting
- SDLC & STLC
- SQL Testing
- Python
- Selenium WebDriver
- Pytest
- Page Object Model
- Basic QA documentation

## Project Structure
- `01_Manual_Testing/` – test plan and test cases
- `02_Bug_Reports/` – defect reporting examples
- `03_SQL_Testing/` – SQL validation queries
- `04_Selenium_Automation/` – Python Selenium automation
- `05_Test_Data/` – sample test data
- `docs/` – project documentation

## How to Run Automation
```bash
pip install -r 04_Selenium_Automation/requirements.txt
pytest 04_Selenium_Automation/tests -v
```

> Replace the example URL/selectors with the target demo application's actual URL and locators.
